
# Pesquisa de Opinião - TudoWeb

## Descrição
Programa desenvolvido em Python para realizar uma pesquisa de satisfação com clientes.

## Funcionalidades
- Coleta do nome dos entrevistados.
- Coleta da idade.
- Registro da opinião sobre o atendimento.
- Contabilização das avaliações.

## Tecnologias
- Python 3

## Conceitos utilizados
- Estrutura de repetição FOR.
- Estruturas condicionais.
- Variáveis e contadores.
